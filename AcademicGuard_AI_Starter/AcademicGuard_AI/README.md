# AcademicGuard AI — نسخة أولية قابلة للتشغيل

منصة ويب عربية لفحص تشابه الأبحاث والأكواد. **الإصدار الحالي محرك تشابه إحصائي وليس نموذج ذكاء اصطناعي**؛ لا يدّعي كشف النصوص المولدة بالذكاء الاصطناعي أو الحكم بالغش. يقارن كل مستخدم ملفاته الخاصة السابقة فقط، ويستخدم TF-IDF وSequenceMatcher. ملفات PDF المصورة تحتاج OCR غير مضمن.

## الإعداد
1. أنشئ مشروعًا مجانيًا في Supabase، ثم نفذ محتوى `supabase/schema.sql` في SQL Editor.
2. انسخ `.env.example` إلى `.env`، وضع `SUPABASE_URL` و`SUPABASE_SERVICE_ROLE_KEY` (مفتاح سري للخادم فقط، لا ترفعه إلى GitHub).
3. انسخ `static/config.example.js` إلى `static/config.js`، وضع رابط Supabase ومفتاح `anon` أو `publishable` العام فقط.
4. ثبّت Python 3.11 أو 3.12. من PowerShell داخل مجلد المشروع:

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python run.py
```

5. افتح http://127.0.0.1:8000 . فعّل تسجيل المستخدمين بالبريد في Supabase Auth. قد يتطلب التسجيل تأكيد البريد.

## النشر أونلاين
ارفع المشروع إلى GitHub **بدون** ملفات `.env` و`static/config.js`. انشره على خدمة تدعم Python ASGI مثل Render (قد تتغير حدود خطتها المجانية)، وأضف متغيرات البيئة السرية في لوحة الاستضافة. أمر البناء `pip install -r requirements.txt` وأمر التشغيل `uvicorn app:app --host 0.0.0.0 --port $PORT`. أنشئ ملف `static/config.js` على الخادم من إعدادات عامة قبل التشغيل (مثل نسخ `config.example.js` وتعديلها أثناء البناء، أو ضم ملف config.js بالمفاتيح العامة فقط). لا تضع service role key في الواجهة أبدًا. Supabase Auth يتطلب إضافة رابط الموقع إلى إعدادات URL Configuration.

## القيود المهمة قبل الاستخدام الجامعي الحقيقي
- الملفات النصية المستخرجة تحفظ داخل عمود JSONB في قاعدة البيانات للمقارنة. لا ترفع بيانات حساسة قبل إعداد سياسة خصوصية وموافقة أصحاب الملفات. الإنتاج يحتاج تشفيرًا مناسبًا، سياسة احتفاظ وحذف، وضوابط مؤسسة.
- المقارنة محصورة بآخر 100 ملف من نفس المستخدم والنوع؛ ليست قاعدة الجامعة كلها. لا يوجد فحص ويب أو بحث مصادر الإنترنت.
- `score` هو أعلى تشابه مع ملف سابق، وليس نسبة اقتباس دقيقة من المستند أو مؤشر غش.
- لا يوجد تحليل دلالي أو JPlag أو Ollama بعد؛ هذه ترقيات مستقبلية وليست مزايا منجزة.
- PDF يستخدم خط ReportLab الافتراضي وقد لا يعرض النص العربي في أسماء الملفات بشكل صحيح؛ تحسين PDF العربي مطلوب للإنتاج.
- يجب إضافة تحديد معدلات الطلبات، فحص الملفات الخبيثة، إدارة صلاحيات المشرفين، ومراقبة الأداء قبل نشره على نطاق واسع.
